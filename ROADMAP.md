# Roadmap

Evidence gates, not promised dates or deployed capabilities:

| Stage | Completion evidence |
| --- | --- |
| Local baseline | Synthetic CPU demo; submission, retries, verification, replay, ledger, cleanup. This is the current prototype. |
| Community baseline | Independent fixtures, platform reports, usable English/Traditional Chinese instructions, and contributor feedback. |
| One real AI workload | User need, permitted model/data, single-machine baseline, output criteria, and measured verification cost. None is selected yet. |
| Two trusted machines | Reviewed protocol/threat model, authenticated transport, bounded resources, dropout/cancellation recovery, no double acceptance, transfer/retry measurements. |
| Limited volunteer pilot | Device-owner protection, restricted workloads, hardware/foreground tests, updates/revocation, abuse handling, validation error rates, and full costs. |
| Sustainable access/rewards | Demand and cost evidence; separate designs for funded compensation and usable/shareable credits. Tradable tokens remain a later separate decision. |

First deliver a useful, measured experiment. Model partitioning, distributed training, public enrollment, real payments, and token launch are outside the current milestone. Comparing existing foundations is part of the work.
